## 未知类型的中值

```cpp
template <class T>
T median(std::vector<T> vec)
{
    typedef typename std::vector<T>::size_type vec_sz;
    vec_sz size = vec.size();
    if(size == 0)
        throw domain_error("median of an empty vector");
    std::sort(vec.begin(),vec.end());
    vec_sz mid = size/2;
    return size %2 == 0 ? (vec[mid]+vec[mid-1])/2 : vec[mid];
}

double median(vector<double> vec)
{
    typedef std::vector<double>::size_type vec_sz;
    vec_sz size = vec.size();
    if(size == 0)
        throw domain_error("median of an empty vector");
    sort(vec.begin(),vec.end());
    vec_sz mid = size/2;
    return size %2 == 0 ? (vec[mid]+vec[mid-1])/2 : vec[mid];
}
```

## 5种迭代器

- 顺序只读访问
- 顺序只写访问
- 顺序读写访问
- 可逆访问
- 随机访问

## 顺序只读访问

```cpp
template <class In, class X> 
In find(In begin, In end, const X & x){
    while(begin!=end && *begin != x)
        ++begin;
    return begin;
}

template <class In, class X> 
In find(In begin, In end, const X & x){
    if(begin==end || *begin == x)
        return begin;
    begin++;
    return find(begin, end, x);
}
```

## 顺序只写访问

```cpp
template <class In, class Out> 
Out copy(In begin, In end, Out dest){
    while(begin!=end)
        *dest++=*begin++;
    return dest;
}
```

## 顺序读写访问

```cpp
template <class For, class X> 
void replace(For begin, For end, const X&x, const X&y){
    while(begin!=end){
        if(*begin==x) *begin=y;
        begin++;
    }
}
```

## 可逆访问

```cpp
template <class Bi> 
void reverse(Bi begin, Bi end){
    while(begin!=end){
        --end;
        if(begin!=end)
            swap(*begin++,*end);
    }
}
```

## 随机访问

```cpp
template <class Ran, class X>
bool binary_search(Ran begin, Ran end, const X &x){
    while(begin < end){
        Ran mid=begin+(end-begin)/2;
        if(x<*mid)
            end=mid;
        else if(x>*mid) begin=mid+1;
        else return true;
    }
    return false;
}
```

## 迭代器的常用操作

操作 | 描述
--- | ---
*iter | 解引用，获取迭代器指向的元素。
iter->member | 访问迭代器指向的对象的成员。
++iter、iter++ | 移动到下一个元素。
--iter、iter-- | 移动到上一个元素。
iter1 == iter2 | 比较两个迭代器是否指向同一位置。
iter1 != iter2 | 比较两个迭代器是否指向不同位置。
iter + n、iter - n | 随机访问迭代器支持的操作。

## Lambda 函数

- 在 C++ 中，Lambda 函数 是一种匿名函数，允许你在代码中直接定义函数对象，而无需显式地定义一个命名函数。
- 基本语法

```cpp
[捕获列表](参数列表) -> 返回类型 {
    函数体
}
```

```cpp
// 定义一个 Lambda 函数，计算两个数的和
auto add = [](int x, int y) -> int {
    return x + y;
};
std::cout << add(2, 3) << std::endl;
// 输出: 5
```

- 捕获列表：用于捕获外部变量，决定 Lambda 函数如何访问外部作用域中的变量。  
- 参数列表：指定 Lambda 函数的参数。  
- 返回类型：可选，指定 Lambda 函数的返回类型。如果省略，编译器会自动推导返回类型。  
- 函数体：Lambda 函数的实现代码。

## Lambda 函数-捕获外部变量

Lambda 函数可以通过捕获列表访问外部变量。捕获方式有以下几种：

- [&]：以引用方式捕获所有外部变量。  
- [=]：以值方式捕获所有外部变量。  
- [var]：以值方式捕获特定变量。  
- [&var]：以引用方式捕获特定变量。

```cpp
int main() {
    int x = 10;
    int y = 20;
    // 以值方式捕获 x，以引用方式捕获 y
    auto lambda = [x, &y]() {
        std::cout << "x: " << x << ", y: " << y ;
        y = 30;
        // 修改 y 的值
    };
    lambda();
    // 输出: x: 10, y: 20
    std::cout << "y after lambda: " << y;
    // 输出: y after lambda: 30
    return 0;
}
```

## Lambda 函数-作为函数参数

Lambda 函数常用于 STL 算法中，例如 std::sort 和 std::for_each。

```cpp
int main() {
    std::vector<int> numbers = {3, 1, 4, 1, 5, 9, 2, 6};
    // 使用 Lambda 函数对 vector 进行排序
    std::sort(numbers.begin(), numbers.end(), 
              [](int a, int b) { return a < b; });
    // 使用 Lambda 函数打印 vector 中的元素
    std::for_each(numbers.begin(), numbers.end(), 
                  [](int n) {std::cout << n << " "; });
    std::cout << std::endl;
    // 输出: 1 1 2 3 4 5 6 9
    return 0;
}
```

## 泛型 Lambda 函数

- 在 C++14 及更高版本中，Lambda 函数支持自动类型推导（auto 参数）。

```cpp
#include <iostream>
int main() {
    // 泛型 Lambda 函数，支持任意类型的参数
    auto add = [](auto x, auto y) {
        return x + y;
    };
    std::cout << add(2, 3) << std::endl; // 输出: 5
    std::cout << add(2.5, 3.7) << std::endl;// 输出: 6.2
    std::cout << add(std::string("Hello, "), std::string("World!")) << std::endl;// 输出: Hello, World!
    return 0;
}
```
