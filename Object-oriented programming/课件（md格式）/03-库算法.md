## 泛型算法

- copy(begin, end, out);
  - 把区间[begin，end)中所有元素完全复制到out开始的元素序列中。
- 泛型算法是一种不属于任何特殊容器的算法，它可以从其参数类型知道如何访问它使用的数据。
- 标准库的泛型算法常常在参数中带有迭代器，算法可以使用这些迭代器来操作底层容器的元素

## 分割字符串—第五章方法

```cpp
vector<string> split(const string & s)
{
    vector<string> ret;
    typedef string::size_type string_size;
    string_size i=0, j;
    while(i!=s.size()){
        while(i != s.size() && isspace(s[i])) ++i;
        for(j=i; j != s.size() && !isspace(s[j]); ++j);
        if(i!=j){
            ret.push_back(s.substr(i,j-i));
            i=j;
        }
    }
    return ret;
}
```

## 分割字符串的另一种方式

```cpp
vector<string> split(const string & str){
    typedef string::const_iterator iter;
    vector<string> ret;
    iter i =str.begin();
    while(i!=str.end()){
        i=find_if(i,str.end(), not_space);
        iter j=find_if(i, str.end(), space);
        if(i!=str.end()){
            ret.push_back(string(i,j));
        }
        i=j;
    }
    return ret;
}

bool space(char c){
    return isspace(c);
}

bool not_space(char c){
    return !isspace(c);
}
```

## 访问两次的解决方案

```cpp
vector<Student_info> extract_fails(vector<Student_info> & students)
{
    vector<Student_info> fail;
    remove_copy_if(students.begin(),students.end(),back_inserter(fail),pgrade);
    students.erase(remove_if(students.begin(),students.end(),fgrade), 
                   students.end());
    return fail;
}
```

remove_copy_if(b,e,d,p):把[b, e)中所有使得谓词p为假的元素复制到d表示的目的地

remove_if(b,e,p):排列容器，使得[b, e)中的元素中，能使得谓词p为假的元素都位于这个区间的头部，返回一个指向这个区间中“不被删除”的元素之后的那个位置的迭代器

## 算法、容器和迭代器-1

- 算法是作用在容器元素上的
- ----它们并不作用在容器上。

```cpp
remove_if(students.begin(),students.end(),pgrade)
```

- 这个调用并没有改变students的大小，只是能使得谓词p为假的元素都位于这个区间的头部，然后保持其他元素不变。当需要缩短这个vector时，我们必须自己完成：

```cpp
students.erase(remove_if(students.begin(),students.end(),pgrade), students.end());
```

- 这里erase是vector的一个成员,它直接作用于容器,而不是容器的元素

## 算法、容器和迭代器

- 算法是作用在容器元素上的
- ----它们并不作用在容器上。
- 容器的操作会使被删除的元素的迭代器无效
  - 例如erase, insert
- 所以在使用这些操作的时候，必须小心地保存迭代器的值。
