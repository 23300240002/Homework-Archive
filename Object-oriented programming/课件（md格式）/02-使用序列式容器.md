## 把学生分类

- 问题：希望知道哪些学生没通过考试。
- 检测函数：

```cpp
bool fgra    return grade(s) < 60 ;
}
```

## 解决问题-最直接方法

- 两个vector：检测每个学生的记录，
  - 一个vector保存及格的学生记录，
  - 另一个保存不及格的学生记录。

```cpp
vector<Student_info> extract_fails(vector<Student_info> &students){
    vector<Student_info> pass, fail;//两个vector
    for(vector<Student_info>::size_type i=0;i!=students.size();++i){
        if(fgrade(students[i])){
            fail.push_back(students[i]);
        }else{
            pass.push_back(students[i]);
        }
    }
    students=pass;
    return fail;
}
//缺点：需要足够的内存来保存每个学生的两份副本。
```

## 解决问题-就地删除元素

```cpp
vector<Student_info> extract_fails(vector<Student_info> &students)
{
    vector<Student_info> fail;//一个vector
    for(vector<Student_info>::size_type i=0;i!=students.size();){
        if(fgrade(students[i])){
            fail.push_back(students[i]);
            students.erase(students.begin()+i);
        }else{
            ++i;
        }
    }
    //students=pass;
    return fail;
}
```

删除第i个元素

循环中会改变

## erase函数

- students.erase(students.begin()+i)

对只支持顺序访问的容器无意义


## 使用迭代器取代索引

```cpp
vector<Student_info> extract_fails(vector<Student_info> & students)
{
    vector<Student_info> fail;

    for(std::vector<Student_info>::iterator 
        iter=students.begin();iter!=students.end();){
        if(fgrade(*iter)){
            fail.push_back(*iter);
            iter=students.erase(iter);
        }else{
            ++iter;
        }
    }

    return fail;
}
```

erase函数返回指向被删除元素之后跟着的元素的迭代器

## 重新设计数据结构以获得更好的性能

- vector的问题：插入和删除费时
- 解决：使用list

## list

```cpp
#include <list>
list<Student_info> extract_fails(list<Student_info> & students)
{
    list<Student_info> fail;

    for(std::list<Student_info>::iterator 
        iter=students.begin();iter!=students.end();){
        if(fgrade(*iter)){
            fail.push_back(*iter);
            iter=students.erase(iter);
        }else{
            ++iter;
        }
    }
    return fail;
}
```

## list Vs. vector

- list顺序访问比vector稍慢些
- 对于大型数据，list删除和插入要比vector快得多
- vector支持索引，而list不支持
  - vector[i] //right
  - list[i] //error!

## 学生信息排序问题

- 对学生信息进行排序的时候调用students.sort()

```cpp
struct Student_info{
```

## map

- map是一种关联式容器，
  - 包含唯一的键值对，即 (key, value)，
  - 内部会根据key值进行排序；
  - 增加、修改和查询具有对数的时间复杂度

## map-2

```cpp
int main(){
    map<int, string> m1;
    m1.insert({2,"c"});
    m1.insert({4,"c++"});
    m1.insert({5,"python"});
    for(auto iter=m1.begin();iter!=m1.end();iter++)
        cout<<iter->first<<" "<<iter->second<<endl;

    map<int, string> 
    m2{{1,"student"},{4,"teacher"},{3,"boy"},{2,"girl"}};

    for(auto iter=m2.begin();iter!=m2.end();iter++)
        cout<<iter->first<<" "<<iter->second<<endl;

    return 0;
}
```

## map-3

```cpp
int main(){
    map<int, string> m3;

    m3.insert({3,“linux”});
    //C++11统一初始化

    m3.emplace(2,“windows”); 
    //最高效,避免临时对象

    m3.insert(std::pair<int32_t, std::string>(1,“mac”)); //传统pair方式
    m3.insert(std::make_pair(5,“unix”)); //make_pair方式

    for(auto iter=m3.begin();iter!=m3.end();iter++)
        cout<<iter->first<<" "<<iter->second<<endl;

    map<int, string> m4 = m1;
    m4[10] = "shell";
    //元素的添加

    m4[7] = "Rust";

    m4[5] = "Java";
    //会替换(5, python)

    for(auto iter=m4.begin();iter!=m4.end();iter++)
        cout<<iter->first<<" "<<iter->second<<endl;

    return 0;
}
```
