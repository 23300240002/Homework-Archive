# 06-操作符重载

## 一个简单的 string 类

```cpp
class Str{
public:
    typedef Vec<char>::size_type size_type;
    // 默认构造函数，创建一个空的Str
    Str(){}
    // 生成一个Str对象，包含c的n个副本
    Str(size_type n,char c):data(n,c){}
    // 生成一个Str对象并使用一个空字串来初始化
    Str(const char * cp){std::copy(cp,cp+strlen(cp),std::back_inserter(data));}
    // 生成一个Str对象并使用迭代器b和e之间的内容对它进行初始化
    template<class In>Str(In b, In e){
        std::copy(b,e,std::back_inserter(data));
    }
private:
    Vec<char> data;
};
```

## List 的简化迭代器

```cpp
template <typename T>
class Iterator {
public:
    Iterator(ListNode<T>* n = NULL) : node(n) {}

    T& operator*() const{ return node->data; }
    T* operator->() const { return &(_node->_data); }

    Iterator& operator++() { node = node->next; return *this; }
    Iterator& operator--() {  node = node->prev; return *this; }

    bool operator!=(const Iterator& other) {
        return node != other.node; }

private:
    ListNode<T>* node;
};
```

## 常量数据成员和引用数据成员初始化

```cpp
class C {
public:
    C(int &r):nine(9),refR(r){ }
private:
    const int nine; // 常量数据成员
    int &refR;      // 引用数据成员
};
```

## 注意

类的常量数据成员不能被赋值，一旦初始化后其值不能改变。引用数据成员也不能被重新指派，初始化后其引用的对象也就固定不能更改。所以不能将上述类C的定义写成如下形式：

```cpp
class C {
public:
    C(int &r)
    {  nine = 9;  // 错误
        refR = r;  // 错误
     }

protected:
    const int nine; // 常量数据成员
    int &refR;      // 引用数据成员
};
```

## 类型转换

构造函数另有一个作用是用于类型转换。C++允许基本类型的数据混合运算。当参与运算的分量是不同的基本类型时，按预定的规则将这些运算分量自动地转换成同一类型，然后进行运算。对于对象来说，有时也有类型转换问题：

```cpp
class Person {
public:
    Person(char *); // 已知名，构建新对象
};
void fn(Person &); // 以person对象的引用为形参的某函数
void main()
{  fn("王明");  // 希望名为王明的无名对象调用函数fn()
}
```

## 友函数和友类

- 为了提高效率, 允许某些特殊的函数从类的外面访问类内的细节。
- 一个类的友函数和友类就是让它们引用其内部细节的一种手段，这是一种破坏数据封装和数据隐藏的机制。
- 类A将某个类A外的函数f或类B说明为它的友函数或友类后，就让函数f和类B能引用类A的私有成员和与继承有关的保护成员。

## 例子

设有两个类,一个是向量类V,另一个是方阵矩阵类M。向量的元素个数和矩阵的列数相同，它们又各自隐藏了自已的细节，但提供了完整的操作，如都有按元素下标存取向量和矩阵元素的函数ele()。如不用友函数，直接定义一个矩阵乘向量的函数mul()如下：

```cpp
#define  N   20

V mul(M & m, V & v)
{ V t;

for(int i = 0; i < N; i++) {

int s = 0;
for(int j = 0; j < N; j++)

s += m.ele(i, j)*v.ele(j);


t.ele(i) = s;

}
return t;

}
```

## 友类

```cpp
class A {
    friend class B;  // 类B是类A的友类
public:   ……
private:
    int x;
};
class B {
public:
    void change(A a);
    ……
};
void B :: change(A a)
{ a.x++;
}
```

- B类中的成员函数就能访问A类的私有成员。
- A类中的函数成员还是不能访问B类的私有成员。
- 声明友类的控制权在自已，只能声明某类是自已的友类，不能声明自已是另一个类的友类。
- 友类关系没有传递性。

## 友函数

class A {

    int x;

## 类的静态成员

- 类的每个对象通常都有该类定义所指定的全部数据成员。但会有一种特殊情况，类的所有对象共享一些数据成员。
- 类的静态数据成员属于类，而不属于对象。
- 类的静态成员函数对类的静态数据成员进行操作。
- 如类有一个计数器，用来记录该类总共有多少个对象，这个计数器应包留在类中。
- 又如类的全部对象被链接成一个链表，即该类的对象是链表上的一个表元。链表需要一个首表元指针，链表的首表元指针应该属于类。

## 例子

```cpp
class Link{
public :
    Link(int x = 0, int y = 0);
    ~Link();
    static Link * findEle(int x, int y);

private :
    int X, Y;
    Link *next;
    static Link *head;
};
Link :: Link(int x, int y)
{
    X = x;  Y = y;
    next = head;
    head = this;

};
Link *Link :: head = NULL;   // 为静态数据成员分配空间，并初始化
```

## 例子-2

```cpp
Link :: ~ Link ()
{  if(head == this) {

cout << "(" << X << "," << Y <<") deleted." << endl;
head = next;  return;

}
for(Link *p = head; p != NULL; p = p->next)

if (p->next == this) {

cout << "(" << X << "," << Y <<") deleted." << endl;
p->next = next;
return;

}

}

Link * Link :: findEle(int x, int y)
{  for(Link *p = head; p != NULL; p = p->next)

// 对head的访问不要对象

       if (p->X == x && p->Y == y)  return p;

return NULL;

}

void main()
{
Link  p1(1, 1);
Link  p2(2, 2);
Link p3(3, 3);

Link *pp = Link :: findEle(2, 2);
if (pp) cout << "Found." << endl;
else cout << "Not found," << endl;
}
```
