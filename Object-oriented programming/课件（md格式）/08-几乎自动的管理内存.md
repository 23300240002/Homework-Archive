# 08-几乎自动的管理内存

## 指针的问题

- 复制一个指针而不复制它所指的对象，当无意中使两个指针指向同一个对象时，会出现令人迷惑的结果
- 销毁一个指针而不销毁它所指的对象，就会产生内存泄漏
- 删除一个对象而不销毁指向它的指针，就会使这个指针成为悬挂指针
- 创建一个指针而不进行初始化,会使指针指向任何地方

## 一个泛型句柄类

- 希望类与它所操作的对象的类之间是彼此独立的，因此这个类必须是一个模板。这个类具有以下几点性质：
  - Handle类型对象是一个指向某个对象的值。
  - 可以对Handle类型对象进行复制
  - 可以通过检测一个Handle类型对象判读其是否指向另一个对象。
  - 如果Handle类型对象指向继承关系树中某个类的一个对象，可以使用Handle类对象触发多态行为。

## 一个可以管理全部类型对象的Handle类

```cpp
template<class T> class Handle{
public:
    Handle():p(0){}
    Handle(const Handle &s):p(0){if(s.p) p=s.p->clone();}
    Handle &operator=(const Handle &);
    ~Handle(){delete p;}
    Handle(T*t):p(t){}
    operator bool() const{return p;}
    T& operator*()const;
    T* operator->()const;
private:
    T* p;
}
```

## 赋值运算符重载

```cpp
template<class T>
Handle<T>& Handle<T>::operator=(const Handle & rhs){
    if(&rhs != this){
        delete p;
        p=rhs.p?rhs.p->clone():0;
    }
}
```

## ＊和->操作符重载

```cpp
template<class T>
T& Handle<T>::operator*() const{
    if(p)
        return *p;
    throw runtime_error("Unbound Handle");
}

template<class T>
T* Handle<T>::operator->() const{
    if(p)
        return p;
    throw runtime_error("Unbound Handle");
}
```

`x->y` 等同于：

```cpp
(x.operator->())->y
```

## 引用计数句柄

- 希望对对象本身进行复制时，不对底层的对象进行实际的复制。
- 使用引用计数来记录有多少个对象指向某个底层对象。

## 象管理指针一样管理引用计数

```cpp
template <class T>
class Ref_handle{
public:
    Ref_handle():p(0),refptr(new std::size_t(0)){}
    Ref_handle(T *t):p(t),refptr(new std::size_t(1)){}
    Ref_handle(const Ref_handle&h):p(h.p),refptr(h.refptr){  ++*refptr;   }
    Ref_handle& operator=(const Ref_handle&);
    ~Ref_handle();
    //同Handle
    operator bool() const{return p;}
    T& operator*()const;
    T* operator->()const;

private:
    T*p;
    std::size_t* refptr;//新加部分
};
```

## 复制

```cpp
Ref_handle(const Ref_handle&h):p(h.p),refptr(h.refptr){
    ++*refptr;
}
```

## 赋值运算

```cpp
template<class T>
Ref_handle<T>&Ref_handle<T>::operator=(const Ref_handle&rhs){
    ++*rhs.refptr;

    //释放左操作数对象，如有必要删除指针
    if(--*refptr==0){
        delete refptr;
        delete p;
    }

    //复制右操作数对象的值
    refptr=rhs.refptr;
    p=rhs.p;
    return *this;
}
```

## 析构

```cpp
template<class T>
Ref_handle<T>::~Ref_handle(){
    if(--*refptr==0){
        delete refptr;
        delete p;
    }
}
```

## 智能指针

- `auto_ptr`：已经不用了
- `unique_ptr`：独占式指针
  - 同一时刻只能有一个指针指向同一个对象
- `shared_ptr`：共享式指针
  - 同一时刻可以有多个指针指向同一个对象
- `weak_ptr`
  - 用来解决shared_ptr相互引用导致的死锁问题

```cpp
#include <memory>
```

## shared_ptr

```cpp
#include <memory>
#include <iostream>
using namespace std;
int main() {
    // 创建一个shared_ptr
    std::shared_ptr<int> ptr(new int(10));
    std::shared_ptr<int> ptr2=ptr;
    (*ptr2)++;
    cout << *ptr << endl;
    return 0;
}
```

## weak_ptr

```cpp
std::shared_ptr<int> shared = std::make_shared<int>(30);
std::weak_ptr<int> weak = shared;
```

- 不控制对象生命周期的智能指针
- 指向由shared_ptr管理的对象但不增加引用计数
- 用于解决shared_ptr的循环引用问题
