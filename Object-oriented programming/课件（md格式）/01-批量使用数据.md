## 计算学生成绩

- 设想有一个课程：
  - 学生的期末考试成绩占最终成绩的40%，
  - 期中考试成绩占20%，
  - 作业的平均成绩占40%。
- 设计程序计算学生的最终成绩

```cpp
{
  cout << "Please enter your first name:";
  string name; //define name
  cin >> name; //read into name
  cout << "Hello, " << name << "!" << endl;
  //ask for and read the midterm and final grades
  cout << "Please enter you midterm and final exam grades:";
  double midterm, final;
  cin >> midterm >> final;
  //ask for the homework grades
  cout << "Enter all your homework grades, followed by end-of-file:";
  //the number and sum of the grades read so far
  int count=0;
  double sum=0;
  double x;//a variable into which to read
  while(cin >> x){
    ++count;
    sum+=x;
  }
  //write the result
  streamsize prec=cout.precision();
  cout << "Your final grade is " << setprecision(3)
     << 0.2 * midterm + 0.4 * final + 0.4 * sum / count
     << setprecision(prec) << endl;
  return 0;
}
```

## 检测输入的结束

- while(cin >> x){/* */}

  - 文件结束：
    - Windows系统： Ctrl＋Z

## vector简介

- 顺序容器
  - 顺序容器中的元素按照严格的线性顺序排序。
  - 可以通过元素在序列中的位置访问对应的元素。
- 动态数组
  - 支持对序列中的任意元素进行快速直接访问。
  - 能够根据需要自动调整自身的大小以便容下所要放入的元素
- 定义模板类对象
  - vector<double> homework;
  - vector<string> s;

## 取中间元素

```cpp
double median = size %2 == 0 ?
                (homework[mid]+homework[mid-1])/2 :
                homework[mid];
```

```cpp
int main()
{
  cout << "Please enter your first name:";
  string name; //define name
  cin >> name; //read into name
  cout << "Hello, " << name << "!" << endl;
  //ask for and read the midterm and final grades
  cout << "Please enter you midterm and final exam grades:";
  double midterm, final;
  cin >> midterm >> final;
  //ask for the homework grades
  cout << "Enter all your homework grades, followed by end-of-file:";
  //read the homework
  double x;//a variable into which to read
  vector<double> homework;
  while(cin >> x){
    homework.push_back(x);
  }
  typedef std::vector<double>::size_type vec_sz;
  vec_sz size = homework.size();
  if(size==0){
    cout << endl <<"You must enter your grades."
       << "Please try agian." <<endl;
    return 1;
  }
  sort(homework.begin(),homework.end());
  vec_sz mid = size/2;
  double median = size %2 == 0 ? (homework[mid]+homework[mid-1])/2 : homework[mid];
  //write the result
  streamsize prec=cout.precision(3);
  cout << "Your final grade is " << setprecision(3)
     << 0.2 * midterm + 0.4 * final + 0.4 * median
     << setprecision(prec) << endl;
  return 0;
}
```

## vector 小结

操作 | 说明
--- | ---
vector<T> v; | 创建一个空的向量，这个向量可以保存T类型的元素
vector<T>::size_type | 表示向量大小的类型
v.begin() | 返回v的第一元素的位置
v.end() | 返回v的最后一个元素之后的位置
v.push_back(e) | 给向量添加一个元素，这个元素的初始值为e
v[i] | 返回v的第i个元素的值
v.size() | 返回v的元素的个数

## 其他库工具

操作 | 说明
--- | ---
sort(b,e) | 将在区间[b,e)中定义的元素按非递减顺序排列
while(cin>>x) | 将一个适当类型的值读到x中并检查流的状态
s.precision(n) | 返回以前的精度，并为以后的输出将流s的精度设为n（如果没有n，则不改变它）。
setprecision(n) | 设置输出流精度为n
streamsize | setprecision所预期的值类型
