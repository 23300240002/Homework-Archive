# Z-order（依据 2025 夏令营回忆重构）

> 本题为依据考生回忆整理的训练重构版；具体措辞和输入格式不保证与原题完全一致。

给定一个边长为 `2^n` 的正方形网格，按以下递归规则从 `1` 开始编号：

- 当 `n=0` 时，唯一格子的编号为 `1`；
- 否则把网格划分为左上、右上、左下、右下四个边长为 `2^(n-1)` 的子网格；按该顺序依次、递归地给四个子网格编号。

给定多个坐标 `(x,y)`，其中 `x` 是行号、`y` 是列号，均从 `1` 开始。求该格子的编号。

## 输入格式

第一行两个整数 `n, T`，满足 `0 <= n <= 25`，`1 <= T <= 10000`。

接下来 `T` 行，每行两个整数 `x, y`，满足 `1 <= x,y <= 2^n`。

## 输出格式

每次询问输出一行编号。

## 样例

```text
输入
2 4
1 1
1 3
3 1
4 4

输出
1
5
9
16
```

本地公开样例 2：

```text
输入
3 4
1 8
8 1
5 6
4 4

输出
22
43
50
16
```

脚本中的样例 3 为 1000 个随机坐标的较大公开样例。
