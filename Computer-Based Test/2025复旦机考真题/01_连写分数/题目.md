# 连写分数（依据 2025 夏令营回忆重构）

> 本题为依据考生回忆整理的训练重构版；具体措辞和输入格式不保证与原题完全一致。

给定一个只包含数字的字符串 `s`，以及 `m` 道特殊题目的分值 `v_1...v_m` 和一种普通题目的分值 `t`。

你需要把 `s` 划分为若干个非空连续子串。每个子串按十进制解释为一个非负整数；除单独的 `0` 外，任何数字不得有前导零。每个数字必须分配给一道题：

- 每道特殊题必须恰好使用一次；
- 普通题可使用任意次；
- 数字不得大于它被分配题目的分值。

求所有划分数字之和的最大值。保证至少存在一种合法方案。

## 输入格式

第一行两个整数 `n, m`，其中 `1 <= n <= 100000`，`0 <= m <= 7`。

第二行一个长度为 `n` 的数字串 `s`。

第三行 `m` 个整数，表示特殊题分值；当 `m = 0` 时该行为空。

第四行一个整数 `t`，表示普通题分值。所有分值均在 `[0, 9999]`。

## 输出格式

输出最大可能总分。

## 样例

```text
输入
4 1
1234
34
12

输出
46
```

一种最优划分是 `12 | 34`：前者使用普通题、后者使用特殊题。

本地公开样例 2（`judge.py` 中可见）：

```text
输入
4 2
0007
0 7
0

输出
7
```

脚本中的样例 3 为长度 200 的较大公开样例。
