# 独立数的中位数（依据 2025 夏令营回忆重构）

> 本题为依据考生回忆整理的训练重构版；具体措辞和输入格式不保证与原题完全一致。

给定长度为 `n` 的整数数组 `a` 与窗口长度 `k`。对每个长度恰为 `k` 的连续子数组，取其中出现次数恰好为一次的所有数，称它们为独立数。

若没有独立数，输出 `no`。否则将独立数从小到大排序，输出其中位数；若独立数个数为偶数，输出中间两个数中较小的一个。

## 输入格式

第一行两个整数 `n, k`，其中 `1 <= k <= n <= 500000`。

第二行 `n` 个整数 `a_i`，满足 `-10^9 <= a_i <= 10^9`。

## 输出格式

对每个长度为 `k` 的窗口输出一行答案。

## 样例

```text
输入
7 4
1 2 2 3 4 4 5

输出
1
3
2
3
```

本地公开样例 2：

```text
输入
4 3
7 7 7 7

输出
no
no
```

脚本中的样例 3 为长度 3000 的较大公开样例。
