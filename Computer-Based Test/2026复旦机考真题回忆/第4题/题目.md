# 第 4 题 最长公共子序列

## 题目描述

给定两个长度均为 $n$ 的数组 $A$ 和 $B$。

已知：

- 两个数组中的元素都在 $1$ 到 $n$ 之间；
- 每个数组都是一个 $1$ 到 $n$ 的排列，也就是说每个整数恰好出现一次。

请你求出这两个数组的**最长公共子序列**长度。

这里的“子序列”指从原数组中删除若干个元素（也可以不删）后，保持剩余元素相对顺序不变所得到的序列，不要求连续。

## 输入格式

第一行输入一个整数 $n$。

第二行输入 $n$ 个整数，表示数组 $A$。

第三行输入 $n$ 个整数，表示数组 $B$。

## 输出格式

输出一个整数，表示两个数组的最长公共子序列长度。

## 输入输出样例 #1

### 输入 #1

```text
5
1 3 2 4 5
3 1 2 5 4
```

### 输出 #1

```text
3
```

## 输入输出样例 #2

### 输入 #2

```text
4
1 2 3 4
1 2 3 4
```

### 输出 #2

```text
4
```

## 说明/提示

- $1 \le n \le 10^6$；
- 对于全部数据，$A,B$ 均为 $1 \sim n$ 的排列；
- 50% 的数据满足 $n \le 5000$；
- 时限：$1$ s；
- 空间限制：$512$ MB。
