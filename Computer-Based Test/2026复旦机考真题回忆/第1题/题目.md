# 第 1 题 扫雷

## 题目描述

给定一个 $n \times m$ 的字符矩阵，矩阵中的每个位置要么是地雷，要么是空地：

- 字符 `*` 表示该位置是地雷；
- 字符 `#` 表示该位置是空地。

你需要根据经典扫雷规则构造输出矩阵：

- 如果某个位置本身是地雷，则该位置仍输出 `*`；
- 如果某个位置是空地，则输出一个数字，表示该位置周围 $8$ 个相邻位置中地雷的个数。

这里“周围的位置”指与当前格子有公共边或公共顶点的所有格子，也就是最多 $8$ 个方向。

## 输入格式

第一行输入两个整数 $n,m$，表示矩阵的行数和列数。

接下来 $n$ 行，每行输入一个长度为 $m$ 的字符串，仅由 `*` 和 `#` 组成，表示原始矩阵。

## 输出格式

输出 $n$ 行，每行输出一个长度为 $m$ 的字符串：

- 若该位置为地雷，则输出 `*`；
- 若该位置为空地，则输出对应的地雷数（字符 `0` 到 `8`）。

## 输入输出样例 #1

### 输入 #1

```text
3 3
*##
##*
###
```

### 输出 #1

```text
*21
12*
011
```

## 输入输出样例 #2

### 输入 #2

```text
2 4
####
####
```

### 输出 #2

```text
0000
0000
```

## 说明/提示

- $1 \le n,m < 10^6$；
- 保证 $n \times m \le 10^6$；
- 时限：$1$ s；
- 空间限制：$512$ MB。
