# 第 2 题 化学式

## 题目描述

给定一个合法的化学式字符串，请你统计其中每种元素出现的总数。

本题中的化学式满足如下递归定义：

1. 一个**元素名**是一个非空字符串，首字母必须是大写英文字母，后续字符若存在则必须是小写英文字母。
2. 若 $X$ 是一个元素名，则 $X$ 本身是一个合法表达式。
3. 若 $X$ 是一个合法表达式， $k$ 是一个正整数，则将 $k$ 写在 $X$ 的后面得到的新串仍是合法表达式，表示将 $X$ 重复 $k$ 次。
4. 若 $A_1,A_2,\dots,A_t$ 都是合法表达式，则它们按顺序直接拼接后得到的串仍是合法表达式。
5. 若 $X$ 是一个合法表达式，则 `(X)` 也是合法表达式；若再在括号后写上正整数 $k$，则表示将括号内整体重复 $k$ 次。
6. 括号可以多层嵌套。

题目保证输入字符串始终合法，不会出现不匹配的括号，也不会出现前导零或非法元素名。

你需要统计最终展开后每种元素的出现次数。

## 输入格式

输入一行，一个字符串 $s$，表示化学式。

## 输出格式

按元素名的字典序从小到大输出。

对于每种出现过的元素，输出一行两个内容：

- 元素名；
- 该元素出现的总次数。

二者之间用一个空格分隔。

## 输入输出样例 #1

### 输入 #1

```text
K4(ON(SO3)2)2
```

### 输出 #1

```text
K 4
N 2
O 14
S 4
```

## 输入输出样例 #2

### 输入 #2

```text
Mg(OH)2
```

### 输出 #2

```text
H 2
Mg 1
O 2
```

## 说明/提示

- $1 \le |s| \le 10^6$；
- 保证所有元素总数均不超过 $10^{18}$；
- 时限： $1$ s；
- 空间限制： $512$ MB。
