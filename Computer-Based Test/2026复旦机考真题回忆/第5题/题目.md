# 第 5 题 充电桩问题

## 题目描述

有 $n$ 个城市，编号为 $1$ 到 $n$。小明要从城市 $1$ 出发，前往城市 $n$。

城市之间有 $m$ 条单向道路。每条道路 $(u,v,w)$ 表示可以从城市 $u$ 到城市 $v$，并且经过这条路会消耗车辆 $w$ 格电量。若当前剩余电量小于 $w$，则无法走这条路。

小明的车有以下参数：

- 初始电量为 $s$；
- 电池容量上限为 $C$，任何时刻电量都不能超过 $C$。

部分城市设有充电桩。在有充电桩的城市中，可以按“每充 $1$ 格电花费多少”的单价付费充电；没有充电桩的城市不能充电。

你需要求出从城市 $1$ 到城市 $n$ 的最小花费。如果无法到达，则输出 `-1`。

## 输入格式

第一行输入四个整数 $n,m,s,C$，分别表示城市数、道路数、初始电量和电池容量上限。

接下来 $m$ 行，每行输入三个整数 $u,v,w$，表示存在一条从 $u$ 到 $v$ 的单向道路，经过该道路会消耗 $w$ 格电量。

接下来 $n$ 行，每行输入两个整数 $id,p$，表示编号为 $id$ 的城市每充 $1$ 格电需要花费 $p$。若 $p=0$，表示该城市没有充电桩，不能充电。

题目保证每个城市的信息都会恰好给出一次。

## 输出格式

输出一个整数，表示从城市 $1$ 到城市 $n$ 的最小花费。

若无法到达城市 $n$，输出 `-1`。

## 输入输出样例 #1

### 输入 #1

```text
4 4 2 4
1 2 2
2 4 2
1 3 1
3 4 4
1 5
2 1
3 10
4 0
```

### 输出 #1

```text
2
```

## 输入输出样例 #2

### 输入 #2

```text
3 1 0 3
1 2 2
1 0
2 0
3 0
```

### 输出 #2

```text
-1
```

## 说明/提示

- $1 \le n,m \le 10^5$；
- $0 \le s \le C \le 40$；
- $1 \le u,v \le n$；
- $1 \le w \le 10^9$；
- $0 \le p \le 10^9$；
- 前 20% 的数据满足所有道路的电量消耗均为 $0$；
- 时限： $1$ s；
- 空间限制： $512$ MB。
