# 第 3 题 缓存

## 题目描述

为了提高查找效率，计算机通常会使用缓存来保存最近或未来仍会用到的数据。现在请你模拟一个简单的缓存系统。

缓存共有 $k$ 个缓存块，编号为 $1,2,\dots,k$。系统会依次处理 $q$ 次查找请求，第 $i$ 次请求查找的内容记为 $a_i$。

缓存的工作规则如下：

1. 若当前查找内容已经在缓存中，则称为一次 **hit**，输出它所在的缓存块编号。
2. 若当前查找内容不在缓存中，则称为一次 **miss**，输出 `miss p`，其中 $p$ 表示本次请求最终被放入的缓存块编号；若本次请求最终没有进入缓存，则输出 `miss 0`。
3. 当发生 miss 时：
   - 如果缓存尚未装满，则将当前内容放入编号最小的空闲缓存块中；
   - 如果缓存已满，则比较“当前请求的内容”和“缓存中已有的每个内容”下一次被访问的时间：
     - 下一次访问时间越晚，优先级越低；
     - 若某个内容后续不会再被访问，则视为它的下一次访问时间为无穷大；
     - 若有多个缓存块并列最晚，则优先淘汰编号较小的缓存块。
4. 若比较后发现“当前请求的内容”本身就是下一次访问时间最晚的那个，则它**不进入缓存**，本次输出中的编号为 `0`。
5. 否则，当前请求的内容会替换掉被淘汰缓存块中的原内容，本次输出中的编号为对应被使用的缓存块编号。

请按照上述规则模拟整个过程。

## 输入格式

第一行输入两个整数 $q,k$，分别表示查找次数和缓存大小。

第二行输入 $q$ 个整数 $a_1,a_2,\dots,a_q$，表示每次查找的内容。

## 输出格式

对于每次查找，输出一行结果：

- 若命中缓存，则输出 `hit p`，其中 $p$ 为缓存块编号；
- 若未命中缓存，则输出 `miss p`，其中 $p$ 为本次请求最终被放入的缓存块编号；若未进入缓存，则 $p=0$。

## 输入输出样例 #1

### 输入 #1

```text
6 2
1 2 3 1 3 2
```

### 输出 #1

```text
miss 1
miss 2
miss 2
hit 1
hit 2
miss 0
```

## 输入输出样例 #2

### 输入 #2

```text
5 3
4 1 4 2 1
```

### 输出 #2

```text
miss 1
miss 2
hit 1
miss 3
hit 2
```

## 说明/提示

- $1 \le q \le 10^6$；
- $1 \le k \le 10^6$；
- $-10^9 \le a_i \le 10^9$；
- 时限：$1$ s；
- 空间限制：$512$ MB。
